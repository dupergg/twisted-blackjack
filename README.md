# twisted-blackjack
Re-upload of a class project: Twisted Blackjack

This is a Java implementation of Blackjack, but with a twist. Two players are playing against each other, and against the dealer, to eliminate the other player. They can bet against each other and whomever loses, takes damage. When a player reaches 0 health, the game ends.
